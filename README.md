# Scientific Computing Foundations

A historical programming repository documenting the development of my Python and computational problem-solving foundations.

This repository is intentionally retained as an **older coding-history anchor** rather than presented as a polished flagship project. It contains practice material, exercises, and exploratory code accumulated while building programming fluency before the newer physics, quantum, and AI projects on this profile.

## Why this repository remains public

The newer repositories are organized around complete projects. This one serves a different purpose: it preserves genuine earlier programming activity and shows the progression from general Python practice toward scientific computing, numerical modelling, data analysis, and research-oriented software.
